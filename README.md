# ひのめ

職人の"みえない"を見える形に。

お客さんに見えない仕事を、職人が話すだけで3Dのページにする道具です。Built with Claude Japan 2026 の期間中に作りました。

作者の父は、ひとりで清掃の仕事をしています。カビ取りでは、床の下まで潜って薬剤を広げますが、その手間はお客さんには見えません。このままでは伝わらないので、話した内容をそのまま3Dにする道具を作りました。

## 流れ

1. 職業など3つの質問に、文字か声で答える
2. Claude が話を深掘りする
3. Claude が台本と3Dのコードを書く
4. 自動で画面を確かめて直す（最大2周）
5. 職人が「ここは違う」と言葉で伝えて直す（何回でも）
6. コードのコピー、動画の保存、リンクの取得で持ち出す（審査員用のサーバーでは、合言葉なしで見られる「見るだけ」のリンクを作ってLINEなどで送れます。リンクはいつでも止められます）

## 大事にしたこと

- **最後に決めるのは職人です。** 自動の確かめは問題を見つけるためのもので、合格を出すものではありません。
- **言っていないことは書きません。** 分からない所は「ここは職人に確認」と画面に出します。
- **言い切れないことは止めます。** 殺菌や効果の保証のような言葉は `studio/guard.py` で止めます。

## 審査員の方へ

提出フォームのリンクと合言葉で、そのまま触れます。無料のサーバーなので、最初の表示に1分ほどかかることがあります。

Claude を呼ぶ回数と同時に動かす数には上限があります（`studio/server.py` の審査員モード）。

## 自分のパソコンで動かす

Python 3 だけで動きます。追加のインストールは要りません。3Dの表示には Three.js を CDN から読み込むので、ネット接続が要ります。

```bash
cd studio
ANTHROPIC_API_KEY=あなたのキー python3 server.py
```

http://127.0.0.1:8986/ を開きます。キーなしで画面の流れだけ見るなら、次のコマンドです。Claude の返事は手書きになり、データは終了時に消えます。

```bash
cd studio
python3 server.py --test
```

## Claude の使いどころ

- **道具の中:** Claude API（`claude-opus-5-5`）が、深掘りの質問、台本、3Dのコード、画面の確かめ、職人の言葉からの直し案を担当します。
- **作る工程:** Claude Code で、コードの全部と見本を作りました。詳しくは [BUILD_LOG.md](BUILD_LOG.md) に書きました。

## 見本と道具の出力の違い

| フォルダ | 中身 | 作り方 |
|---|---|---|
| `studio/` | 道具本体 | Python 標準ライブラリのみ |
| `kabi/` | カビ取りの作り込み見本 | 父の話をもとに、Claude と時間をかけて作り込んだもの。道具の一発の出力ではありません |
| `kabi_correct/` | 「ここは違う」で直す仕組みの試作 | カビの見本で使います |
| `tsugaru/` `sakan/` `tsugite/` `ringo/` `rousui/` | ほかの仕事の見本 | 公開資料をもとに手をかけて作ったもの。出典は各 `SOURCES.md` です |

道具が作るページの見た目は、見本とは違います。

## デモ動画について

- 父の声は本人の録音で、本人の許可を得ています。AI で声を作ってはいません。録音と写真はこのリポジトリに入れていません。
- 道具の画面は、保存済みの作例のデータを使って実際の画面を収録しました。声入力の場面は実際に操作して録画しました。
- 「ここは違う」の場面は、本物の Claude の返事（1回ぶん）を保存し、その返事で再生して撮影しました。
- 道具を操作しているのは作者です。父が操作しているわけではありません。
- 3Dの絵は説明のために描いたもので、形や層の厚みは実物と同じではありません。
