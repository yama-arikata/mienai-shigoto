# 見えない仕事を、3Dで見せる

職人が質問に答えると、お客さんに見えない仕事を3Dにする道具です。Built with Claude Japan 2026 の期間中に制作しています。

- `studio/` 道具本体（Python標準ライブラリのみ）
- `kabi/` カビ取りの作り込み見本（道具の一発の出力とは別物）
- `kabi_correct/` 「ここは違う」で直す仕組みの試作
- `ringo/` `rousui/` `sakan/` `tsugaru/` `tsugite/` 他の仕事の見本（出典は各 `SOURCES.md`）

本人の録音と写真は、このリポジトリに入れていません。動画に出てくる声と写真はここにはありません。

このリポジトリは、作業の途中の 2026-11-06 に作りました。それまでのファイルは最初のコミットにまとめて入っています。
