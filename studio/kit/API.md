# K の使い方（見えない仕事ページの土台）

あなたが書くのは「関数の中身」だけ。スクロール、字幕、カメラの動き、照明の設定、画面の大きさへの対応は土台がやる。
`K` だけが使える。`document` `window` `fetch` `import` は使えない（書くと止まる）。

## 全体の形
```js
const {world,box,wood,go,on,since,until,fade,label,ss,mix} = K;
const w=world('workshop');       // ★最初に場所を作る（1回だけ）。光・空・床・背景の飾りまで全部入る
const a=box(1.2,.4,.6,wood({base:'#b98d5c',late:'#8b633c'}),{at:[0,.2,0],name:'土台の木'});
return function(p,t){            // 最後に必ず返す。毎フレーム呼ばれる
  a.position.y=.2+go('lift')*.5; // 場面 lift の間に上がる
};
```
- **単位はメートル。y=0 が床**、主役は原点の近くに置く。実物の大きさで作る（車の長さ4.6、ふすまの高さ1.8、家の幅7）。
- `t` は秒。ゆらぎに使う。`p` は 0〜1 のスクロール位置。**数字で p を書かない。場面の名前で書く。**

## 場所（必ず最初に K.world。暗い床だけの場面は検査で止まる）
`const w=world(種類,{...})`。**world を使うときは light / ground / wall を呼ばない**（光も床も入っている）。
| 種類 | 絵 | よく使う指定 |
|---|---|---|
| `snow_night` | 雪の夜の外。街灯・雪の森・遠くの家・降る雪 | `clear:6`（主役のまわりの空き地の広さ）`snow:220` |
| `garage` | 車の作業場。蛍光灯・鉄の壁・棚の荷物・シャッター | |
| `workshop` | 木の作業場。板の壁・作業台・道具棚・窓の光 | |
| `room` | 家の部屋。`japanese:true` で畳と障子 | `w,d`（広さ）`wall`（壁の色）`floor`（床の種類） |
| `town_dusk` | 夕方の町。道路・街灯・遠くの家 | |
| `field_day` | 昼の屋外。空・山・木・柵 | `ground:'grass'|'soil'|'gravel'`、`fence:false` |
| `studio` | 物だけを見せる撮影台 | `tone:'light'`（明るい地）`color` |
- 返り値 `w.dim(a)`: 世界全体を暗くする（1=ふつう、.3=暗い）。**見せ場で暗くして、見えないものを主役にする**。
- 世界の飾り（木・家・棚の荷物）は背景です。仕事の事実ではないので、職人が言っていなくてもかまいません。

## 主役の部品（箱を積まない。あるものは必ずこれを使う）
- **`car({kind,color,at,rot,seat})`** 車。kind = `wagon` `sedan` `kei` `van` `suv`。全長4.6くらいで前は +x。ボディ・窓・タイヤ・ホイール・座席・ハンドル・マットまで入っている。**車を自作しない。**ライトは消えている（夜に走っている絵だけ `lights:true`）。
  - `c.spot(名前)` 車の中の場所の座標。名札やしみの位置に使う: `front_mat_r front_mat_l rear_mat_r rear_mat_l rear_floor seat_front_r seat_front_l seat_rear seat_back_rear cargo dash handle center roof hood door_r door_l wheel_front wheel_rear window nose tail`
  - `c.see(a)` 外側を透かす（0=ふつう、1=輪郭だけで中が見える）。中の明かりもつく。`c.shell` 外側 `c.cabin` 中 `c.length` `c.height`
- **`house({w,d,h,at,rot,wall,roof})`** 家（前は +z）。屋根・窓・玄関・基礎つき。`h.see(a)` で透かす。`h.inner` に足すと中の物になる。`h.fh` 床の高さ `h.roofY` 屋根の高さ
- **`bottle({h,r,at,color,cap,text,labelColor,name})`** 入れ物。text はラベルの文字（`\n` で改行）。**商品名は書かない。**
- `wheel(半径,幅,{at,side,rim,tire})` タイヤ
- **`strata([{h,mat,name},...],{w,d,at,rot,gap,axis,stair})`** 重なった層。**塗り・紙・地面・断熱材など「何層も重なる」ものは、自作せず必ずこれを使う。** h は層の厚み。
  - `axis:'y'` 下から上へ（地面・床）/ `axis:'z'` 奥から手前へ（壁・ふすま）。壁の前面にぴったり付けるときは at を壁の表面に置く。
  - **`stair:.25`** 上の層ほど右を短くして、**階段のように全部の層が見える**。層の枚数が絵から数えられる。
  - `.open(a,gap)` 層を離して見せる（a=0〜1）。`.parts[i].m` 各層。`.center(i,a,gap)` 層の中心。**`.spot(i,a,gap)` その層の見えている表面の座標＝名札の点はこれを使う。層が3つなら名札も3つ、層ごとに付ける。**
- `loft(x0,x1,縦の数,横の数,(x,角度)=>[y,z],mat,o)` 長い物を輪郭で作る（管・車体のような形）。`pillow(幅,高さ,奥,丸み,ふくらみ,mat,o)` ふくらんだ箱（座席・袋・布団）
<!--clay-->
- **`clay([玉やカプセル,...],mat,{smooth,res,at,rot,name})`** 粘土。玉・カプセル・楕円・角丸箱を**なめらかにくっつけて1つの塊**にする。**人・手・腕・作業着・袋・動物・ふくらんだ服・こねた土のような「ぐにゃっとした形」はこれで作る**（箱や円柱を積まない）。作るのは最初の1回だけ（毎フレーム作らない）。
  - 1つずつ `{ball:[x,y,z],r}` 玉 / `{cap:[[x,y,z],[x,y,z],...],r}` カプセル（点を3つ以上つなぐと曲がった腕や指。`r:[.08,.06,.05]` で点ごとに太さを変える）/ `{ell:[x,y,z],r:[x半径,y半径,z半径]}` 楕円 / `{rbox:[x,y,z],size:[幅,高さ,奥],r:角の丸み}` 角丸箱。
  - 1つずつに足せる: `color:'#rrggbb'`（**色ごとに別の塊**になり、境目はくっきり。手ぶくろ・長ぐつ・マスクに使う）/ `pair:true`（x を反対にした左右の対も作る。腕・脚・耳）/ `sub:true`（その形でくりぬく。口・穴・くぼみ）/ `k:.02`（その1つだけのくっつき具合。小さいほどくっきり）。
  - `smooth` くっつくときの丸みの幅（メートル、ふつう .03〜.08）。`res` 細かさ（ふだんは書かない。細い所に合わせて自動で決まる。上げると重い）。
  - **人の形を作るときは顔を作らない**（頭は丸いまま・マスクやフードでおおう）。前は +z、身長は1.6〜1.75。`rot:[0,角度,0]` で向きを変える。
  - 名前は `K.clay`。材質の `surface('clay')`（土壁）とは別のもの。
```js
// 人（作業着）。左右は pair、手ぶくろは色を変える
const man=clay([
 {cap:[[.11,.1,0],[.11,.5,.02],[.1,.88,0]],r:[.075,.085,.1],pair:true},   // 脚
 {ell:[0,1.15,0],r:[.21,.3,.15]},{ball:[0,1.6,0],r:.12},                  // 胴と頭
 {cap:[[.2,1.38,0],[.27,1.12,.1],[.18,1.02,.28]],r:[.08,.065,.055],pair:true}, // 腕
 {ball:[.18,1.02,.31],r:.05,color:'#3f86c8',pair:true},                   // 手ぶくろ
 {cap:[[.11,.06,-.01],[.11,.06,.13]],r:.065,color:'#33373c',pair:true},   // 長ぐつ
],std({color:'#ecebe6',roughness:.6}),{smooth:.06,at:[0,0,0],name:'作業する人'});
// 袋（口をしばった麻袋）
clay([{ell:[0,.3,0],r:[.28,.3,.22]},{cap:[[0,.55,0],[0,.68,0]],r:[.06,.09],k:.03}],surface('cloth',{color:'#b59a6a'}),{smooth:.08,at:[1,0,0],name:'袋'});
// 手（にぎった形）。指はカプセルを曲げてつなぐ
clay([{ell:[0,0,0],r:[.045,.02,.05]},{cap:[[-.03,0,.05],[-.035,-.015,.08],[-.03,-.04,.075]],r:.011,pair:true},{cap:[[0,0,.05],[0,-.02,.085],[0,-.045,.075]],r:.012}],
 std({color:'#d9b48f',roughness:.55}),{smooth:.015,at:[0,1,.3],name:'手'});
```
<!--/clay-->
- 部品が無い物は、**先に輪郭を考える**。`lathe`（回転体）`shape`（押し出し）`loft` `pillow` で形を作り、段・すき間・ふち・留め具・足を足す。遠くから影だけ見て何か分かる形にする。

## 見えないものを見せる（見せ場の主役。周りとはっきり違う色にする）
- **`wisp(座標,{n,spread:[x,y,z],height,width,color,color2,opacity,name})`** におい・湯気・熱・空気。ゆらゆら立ちのぼる帯。`.set(高さ0〜1,濃さ0〜1)`。全部で36本くらいまで。**橙・赤・黄・琥珀は火に見えるので使えない**（自動で淡い黄緑に変わる。何も書かなくても淡い黄緑）
- **`stain(座標,半径,{color,edge,normal,name})`** しみ・ぬれた所・カビでない汚れ。`.set(濃さ,広がり)`。床ならそのまま、壁なら `normal:[0,0,1]` のように面の向きを渡す
- **`flow([[x,y,z],...],{r,speed,color,name})`** 水・電気・空気の流れ。管の中を流れる点線。`.set(どこまで0〜1,濃さ)`
- **`spray(ノズルの座標,当たる所の座標,{spread,n,speed,width,color,name})`** 高圧の水・塗料の吹きつけ。細い筋がノズルから当たる所へ飛ぶ。`.set(濃さ)`。**水の勢いは自作せずこれを使う。** 当たった所のぬれは stain で足す
- **`xray(物,{color})`** 外側を輪郭だけにして中を見せる。`.set(a)`。車と家は `see` を使う
- **`cut(物,{normal,at})`** 物を切って断面を見せる。`.set(切る量0〜1,どこまで)`
- `glow(座標,大きさ,色,濃さ)` ふわっと光る玉。`.set(a)`。1場面に1つ
- `blob(座標,x半径,z半径,濃さ)` 床に落ちる丸い影
- これらを使った場面の字幕には、台本の `image_note`（例: においを色の帯で表した絵です）が「イメージ」の印と一緒に自動で出ます。
- **効き目を言い切る絵にしない。** においやしみが完全に消える絵は作らない（薄くなる途中までにする）。職人が言っていない工程を動きで見せない。

## 場面の進み具合（場面の順番を変えても動きが崩れる心配がない書き方）
| 関数 | 返す値 |
|---|---|
| `go(id, from=0, to=1)` | その場面の from〜to の間に 0→1。前は0、後は1のまま |
| `on(id)` | その場面の間だけ 1、前後は0 |
| `since(id)` | その場面が始まってから最後まで1 |
| `until(id)` | その場面が終わるまで1、後は0 |
`ss(a,b,x)` なめらか0→1 / `mix(a,b,t)` / `clamp(x,a,b)` / `seq([[x,値],...],x)` / `rnd(a,b)`（毎回同じ乱数）

## 材質
- `wood({base,late,rings=12,scale=1,along:'x'|'y'|'z',seed})` 木。模様が立体で入っていて切り口に年輪が出る。**木目の向きを along で合わせる**。細い材は scale:2〜3。
- `surface(kind,{color,scale,bump,rough})` 面の質感。UV不要。kind = plaster(しっくい) clay(土壁) soil(土) gravel(砕石) concrete asphalt paper cloth stone rust sand
- `std({color,roughness,metalness,map,...})` ふつうの材質 / `metal(color,rough)` / `glass(color,opacity)` / `water(color)` / `emit(color,power)` 光る物
- `tex(size,(g,s)=>{...},rx,ry)` 2Dキャンバスで模様を描く（box / plane の `map` に）。`speckle(g,s,base,cols,n,rmax)`
- 色は '#rrggbb'。真っ黒は土台が少し明るくする。**黒い物も形が読める色にする（#2a2a2a 以上、タイヤなら溝を形で作る）**

## 形（どれも影つき。最後の引数 o は省略可）
`box(w,h,d,mat,o)` `rbox(w,h,d,r,mat,o)`角丸 `cyl(上半径,下半径,h,mat,o)` `ball(r,mat,o)` `plane(w,h,mat,o)`
`lathe([[半径,高さ],...],mat,o)`回転体 `shape([[x,y],...],厚み,mat,o)`押し出し `tube([[x,y,z],...],太さ,mat,o)`管
`group(o)` 物をまとめる。`ground(kind,o)` 床 `wall(kind,{z,height,color})` 奥の壁
o = `{at:[x,y,z], rot:[x,y,z], scale, name:'日本語の名前', parent:group, shadow:false}`
**主な物には必ず name を日本語で付ける**（本人が3Dを指して「ここは違う」と言うときに使う）。
細かい形が要るときは `K.THREE` で自作してよい（`scene.add` は `K.scene.add`）。ただし外から何も読み込めない。

## 出す・消す・目印
- `fade(物, 0〜1)` 物やグループをふわっと出す・消す。`物.visible=false` でもよい
- `dust({at,n,spread:[x,y,z],vel:[x,y,z],gravity,size,color})` 粉・水滴。返り値 `.set(進み具合0〜,濃さ0〜1)`。**1回260粒、全部で700粒まで**。粒で中を隠さない
- `mist({at,n,spread,vel,size,color})` 霧。返り値 `.set(進み具合,濃さ)`。濃さは上限つき
- `ring([x,y,z],半径,色,{rot})` 目印の輪、`arrow(from,to,色)` 矢印。返り値 `.set(濃さ)`。**光らせるのは1場面に1つ**
- `label('文字',[x,y,z],{on:'場面id'})` 物に名札。文字は短く。**1場面3つまで（超えると止まる）**。職人が言っていない名前は付けない。**点 [x,y,z] は物の表面に置く。** PCでもスマホでも、画面の外・字幕の下・物の裏に点が入ると検査で止まる。外側を透かしてから見える物の名札は `{on:'場面id',from:.6}` のように、透けたあとで出す
- `light(...)` `bg(...)` `fog(...)` は world を使うときは要らない

## カメラ（別の欄に書く。コードでは動かさない）
場面ごとに2つ、`{look:[x,y,z], r:大きさ, dir:[x,y,z]}` を書く（入ったときと出るとき）。
- `look` どこを見るか。`r` その物の半径（見せたい物が丸ごと入る大きさ。車の全体なら2.4くらい、車の中なら1.8くらい）。`dir` どちらから見るか（look から見たカメラの方向。[0,.2,1] なら正面少し上）。
- **距離は土台が r から計算する**ので物が画面に入りすぎない。PC では左に字幕が出て物は右に寄る。スマホでは下に字幕が出て物は上に寄る。どちらも土台が合わせる。
- 物の裏や壁の向こうにカメラを置かない（dir を確かめる）。前をふさぐ物があると検査で止まる。
- 同じ場面の2つは少しだけ変える（ゆっくり寄る・回る）。隣の場面とは見る物か向きをはっきり変える。

## 良い絵にするために（お客さんに見せて恥ずかしくない絵）
1. **場所**: 最初に world。その仕事らしい場所で、主役が地面にちゃんと立っている。
2. **主役**: 実物の大きさ・実物の形。遠くから影だけ見て何か分かること。部品があるものは部品を使う。無いものは輪郭から作り、面取り・段・すき間・ふち・留め具を足す。
3. **見えないもの**: ふだん見えない層・裏・におい・湿り・流れ・順番・待ち時間を、形と色にして見せる。切り口を見せる、層を分ける、外側を透かす、世界を暗くする。
4. **見せ場を1つ**: `w.dim` で暗くして、見えないものを画面の真ん中に大きく出す。カメラも寄る。この場面がページの顔。
5. **場面ごとに絵を変える**: 字幕を隠しても何の場面か分かること。同じ絵が続かない。見る物か向きを変える。
<!--noclay-->6. 人の形は作らない。道具が動き、物の様子が変わることで作業を見せる。職人が言っていない道具は作らない。<!--/noclay--><!--clay-->6. 人は主役にしない。要るときだけ `clay` で、顔を作らずに出す（手・腕・作業着の人）。箱や円柱で人を作らない。道具が動き、物の様子が変わることで作業を見せる。職人が言っていない道具は作らない。<!--/clay-->
7. 暗い床に暗い物を置かない。黒い物は #2a2a2a 以上。
8. 動きは意味のあるものだけ。ずっと回す・光らせるはしない。毎フレーム物を新しく作らない。
